# Engine failure (emergency)
<!-- F-16C, simplified memory items. Not for real flight. -->
- Speed: 250 knots for gliding
- Throttle: OFF, then MIDRANGE for a restart
- JFS: START 2, below 400 knots and below 20,000 feet
- EPU: ON
- If the engine won't turn: head for the nearest runway or decide on ejection
- Radio: Mayday, position and intentions
