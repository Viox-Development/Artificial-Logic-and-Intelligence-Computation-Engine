# Engine start
<!-- F-16C, simplified cold start. Copy it under ~/.alice/checklists/ and change it to your own list. -->
- Canopy: closed and locked
- Main power: MAIN PWR
- Warning lights: tested
- Fuel master switch: MASTER ON
- JFS: START 2, RUN light on
- Throttle: IDLE at 20 percent rpm
- Engine: rpm and temperature normal, JFS off
- Main and standby generators: lights out
- EPU: checked
- Avionics: MMC, ST STA, MFD, UFC, GPS on
- INS: aligning (ALIGN NORM)
- Radio and IFF: set
- Canopy: ready for takeoff
